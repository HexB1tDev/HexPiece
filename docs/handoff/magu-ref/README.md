# Magu Magu no Mi: reference GIFs (Akainu / Sakazuki)

The owner, 2026-11-22: "Now do the same as you did with the Gurunomi for the Magunomi, the Magma fruit that is already in the game but
has no abilities as well. Search for Akainu's feats and gifts for reference and make his abilities. Make sure not to animate the feet,
like the legs, unless it's absolutely needed."

46 Tenor GIFs (searches akainu-magma, akainu-punch, akainu-ace, akainu-meteor-volcano, akainu-vs-aokiji, akainu-sakazuki, akainu-luffy,
akainu-marineford; 201 MB, too big for the repository). `sheets/` holds every one as a row of 6 frames, 7 a sheet (`sheet-00-06.jpg`
is 00 to 06). The full GIF of each: `https://media.tenor.com/<id>AAAAC/<name>.gif` (the id is the last part of each row's label).

What they agree on (the look to copy): magma drawn flat and cel-shaded, **orange-red with yellow-white hot spots and a black crust**
(black outlines and cracks over it), thick and dripping; it throws **black-brown smoke** that billows up in huge clouds; where it
lands it burns and the ground glows red.
